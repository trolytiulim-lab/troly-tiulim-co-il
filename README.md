# Trolley Trips Landing Page

תבנה לי דף נחיתה בעברית (RTL) מודרני, נקי ומזמין עבור סוכנות נסיעות בשם Trolley Trips.



כל הטקסט בדף חייב להיות בעברית מלאה:

1. כותרת ראשית: טרולי טיולים | עפים על החופשה הבאה שלכם 🎒✈️

2. תת כותרת: מתכננים לכם טיולים אקטיביים, חוויות מטורפות ומסלולים מדויקים – בלי להתברבר ובראש שקט.

3. 3 יתרונות מרכזיים: אפס כאב ראש, קצב נכון ואקשן, זמינות מלאה בוואטסאפ.

4. כפתור הנעה לפעולה: כפתור ירוק ובולט שכתוב עליו "תכננו לי טיול בוואטסאפ".

5. עיצוב: סגנון נקי ויוקרתי, צבעים של חופשה וים.

6טרולי – לגלגל בקלות לכל העולם אפשר להוסיף
